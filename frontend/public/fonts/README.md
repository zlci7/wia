# WIA Display

`wia-display-bold.woff2` is a locally served Chinese display face derived from [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc), at weight 700. It contains Latin, Chinese ideographs, Chinese punctuation and full-width characters. Its family name is WIA Display.
