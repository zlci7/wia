# 共创游玩参数与参照验收

日期：2026-10-07。范围：U1 的请求参数接线与真实创作参照。

## 工程合同

文本请求支持默认、关闭、低强度和高强度思考。DeepSeek 将显式选择映射到 `thinking.type` 与 `reasoning_effort`；流式传输单独选择。关闭思考时，上下文构建与传输均保留原有正文上限，额外推理预留为零。现有调用未指定模式时沿用 Provider 默认值，单次关闭不会改变后续默认请求。

当前 OpenAI 接入尚不支持该显式选择，请求在网络发送前明确失败。参数与支持边界由程序校验。

参数依据为 [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。该文档说明默认启用高强度思考，支持显式关闭与强度选择。

模型、两个 Provider 与 Turn 的针对性测试、race 和 vet 通过。覆盖有效载荷、非法模式、关闭思考的预算、传输与观察回调，以及不支持时的网络前拒绝。全仓基线测试在开发前通过；最终全仓回归单独记录。

## 真实参照

内部参照测试在隔离世界装配现有场景请求，以同一份输入分别比较纯正文和完整候选返回。请求显式关闭思考，保留原有输入与正文输出上限；参照不提交世界结果，也不自动增加技术重试。

首个纯正文请求在约 0.947 秒返回 HTTP 401，未进入生成，未获得有效用量。后续参照停止。该次测试误用了数据根下旧 Runtime 的配置路径。正式 WIA 的默认配置位于 `story-app/config/model.json`，由 `app.Open` 选择；用户配置没有修改。

首次失败证据见[参照请求](evidence/co-creative-reference-2026-10-07/reference.json)。记录包含模式、请求摘要、上限、诊断与实际结果，不包含密钥或模型思考。

## 正式配置复测

正式配置的最小请求返回 HTTP 200，约 0.723 秒，输入 9 token、输出 1 token、推理 0 token，结果为 `OK`。

随后对同一份冻结场景输入进行两次非流式对照，均显式关闭思考：

| 返回合同 | 耗时 | 输入 token | 输出 token | 推理 token |
| --- | --- | --- | --- | --- |
| 纯正文 | 2.996 秒 | 6,181 | 298 | 0 |
| 完整结构化候选 | 6.205 秒 | 6,514 | 1,297 | 0 |

输入材料摘要一致，系统提示的返回合同不同。两次 Provider 响应完整；结构化字段与原子提交未在该创作参照中验收。测试没有提交世界变化，没有调用自动纠正。证据见[正式配置对照](evidence/co-creative-reference-formal-2026-10-07/reference.json)。

这些结果验证参数控制与该单次输入的生成完整性，不构成连续质量、正式迁移或普遍速度结论。
