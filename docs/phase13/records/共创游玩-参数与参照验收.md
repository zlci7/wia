# 共创游玩参数与参照验收

日期：2026-10-07。范围：U1 的请求参数接线与真实创作参照。

## 工程合同

文本请求支持默认、关闭、低强度和高强度思考。DeepSeek 将显式选择映射到 `thinking.type` 与 `reasoning_effort`；流式传输单独选择。关闭思考时，上下文构建与传输均保留原有正文上限，额外推理预留为零。现有调用未指定模式时沿用 Provider 默认值，单次关闭不会改变后续默认请求。

当前 OpenAI 接入尚不支持该显式选择，请求在网络发送前明确失败。参数与支持边界由程序校验。

参数依据为 [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。该文档说明默认启用高强度思考，支持显式关闭与强度选择。

模型、两个 Provider 与 Turn 的针对性测试、race 和 vet 通过。覆盖有效载荷、非法模式、关闭思考的预算、传输与观察回调，以及不支持时的网络前拒绝。全仓基线测试在开发前通过；最终全仓回归单独记录。

## 真实参照

内部参照测试在隔离世界装配现有场景请求，以同一份输入分别比较纯正文和完整候选返回。请求显式关闭思考，保留原有输入与正文输出上限；参照不提交世界结果，也不自动增加技术重试。

首个纯正文请求在约 0.947 秒返回 HTTP 401，未进入生成，未获得有效用量。后续参照停止。该结果表明当前配置认证失败，不能据此判断思考参数、正文质量、耗时收益或结构化输出效果。

诊断证据见[参照请求](evidence/co-creative-reference-2026-10-07/reference.json)。记录包含模式、请求摘要、上限、诊断与实际结果，不包含密钥或模型思考。真实参照仍待可用的已授权配置。
