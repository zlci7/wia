# 轻量共创连续游玩验收

日期：2026-10-07。范围：Phase13 内部共创原型。实施与评审由同一开发者完成，没有独立 Agent 审查。

## 工程结果

内部入口为 `backend/cmd/wia-play`。集中创作采用正文、结束位置与个人连续性事项，复用 Turn 的上下文入口、材料授权、MemorySource、整组检索、世界时钟和地点连接。普通调用显式关闭思考并启用 DeepSeek JSON 输出，仍执行本地严格解码、引用和范围检查。

机制测试通过：普通一次调用、推进与传输选项、个人记录与说话者自有记录、短名与前轮人物关联、当前位置优先、旧约定召回、结束位置完整性、有向可达性、重复键、未知字段、必要字段、一次纠正、材料补充、Provider 失败与截断、取消、忙碌预约、调用前容量拒绝及副本所有权。离线海港配置验证通用代码与材料注入。

全仓 `go test ./... -count=1`、受影响 Turn/Model/DeepSeek/OpenAI/CLI 包的 `go test -race`、`go vet ./...` 和两个命令构建通过。追加的容量与可达性测试由 Turn race 回归覆盖。前端代码没有改动。

## 连续会话

模型为现有配置的 `deepseek-v4-flash`，剧本为 `mist-embers.pack.v9`；两段均关闭思考，输入估计上限 12,000，可见输出上限 4,096，整轮截止 300 秒，每段请求上限 16。

| 样本 | 接受轮数 | 实际请求 | 技术纠正 | 整轮中位耗时 | 整轮范围 | Provider 输入 / 输出 token |
| --- | --- | --- | --- | --- | --- | --- |
| 主动调查、流式 | 12 | 14 | 2 | 4.6445 秒 | 2.704～9.329 秒 | 93,035 / 9,092 |
| 人物主动性、非流式 | 12 | 13 | 1 | 5.6315 秒 | 4.749～12.951 秒 | 86,564 / 10,676 |

两段均完成 12 轮，21 轮一次核心调用，3 轮两次核心调用，没有未接受回合。流式每次请求首个文本片段为 406～790 毫秒，片段仍是候选内容。输入估计峰值分别为 11,923 和 11,752，未提高本地输入上限。

证据：[调查 JSON](evidence/co-creative-play-2026-10-07/investigation.json)、[主动性 JSON](evidence/co-creative-play-2026-10-07/initiative.json)、[完整正文](轻量共创-对话文本.md)。JSON 保留原文、推进选项、模型与传输参数、每次响应、Provider 用量、耗时和接受后的时空。

最后补充既有叙事视角指令，单轮真实复测 5.327 秒接受，正文使用第二人称。该补充只有单轮真实证据；之前两段的记录保留原状。见[视角复测](evidence/co-creative-play-2026-10-07/perspective.json)。

Provider 没有单独报告这些关闭思考请求的推理 token；诊断中 `ReasoningKnown=false`，零值不是独立的用量测量。未收到推理文本。

## 文本评审

| 项目 | 实际观察 |
| --- | --- |
| 追问与走访 | 争执、字迹、收据和时间顺序得到回答；进店与返所承接到后续情境 |
| 多人回应 | 马丁与书记员讨论登记与家庭边界；艾琳与排字工各自补充现场信息 |
| 私聊和记忆 | 窗边限定谈话后，书记员表示不知道承诺内容；马丁在后续记得找到诺拉后先听本人意见 |
| 主动性 | 艾琳提出可核实的线索和自己的后续安排，玩家拒绝合作后仍保留拒绝 |
| 玩家选择 | 样本没有收取报酬或自动接受委托，最后仍由玩家决定是否继续 |
| 位置连续性 | 结束位置记录了送别后返店；随后按实际所在地再次接触马丁 |

当前结果支持内部试玩评审，不构成普遍可靠性或长期记忆结论。物件位置、NPC 对往事的补充和普通多步骤行动的完整程度仍须用户实际游玩评审；程序不将证词直接升级成真相。结构通过不能证明正文每个细节一致。

## 失败与请求总量

早期调查第九轮在两次 HTTP 200 响应后仍被严格 JSON 校验拒绝；已有八轮情境保留。之后的记录还包含结束位置遗漏、重复路线、输出传输元数据与错误事项类型。所有拒绝、纠正和完整响应保留在同一[证据目录](evidence/co-creative-play-2026-10-07/)。它们不计入上表的最终连续样本。

共创开发与诊断共 80 次 HTTP 200 请求，累计 Provider 输入 515,874、输出 55,543 token，包含失败结果与纠正。加上 U1 的一次连接测试、两次创作参照及一次错误配置的 401，本轮共 84 次请求尝试；已报告的输入总量 528,578、输出总量 57,139 token。401 没有可用用量。金额与账户剩余额度没有读取或推算。

原始模型思考、密钥、本机配置与用户存档不在证据中。

## 验收边界

正式网页仍运行 `Service.Execute`；旧完整候选及其机制测试保留为后续正式迁移依据。原型没有提交数据库或验证存读档，也未执行完整经济、物品、判定和世界发展矩阵。正式迁移、完整机制与最终实机质量验收分别交付。
