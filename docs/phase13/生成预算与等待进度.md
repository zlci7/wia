# Generation budget and waiting progress

## Turn budget

`turn.GenerationTimeBudget` is 300 seconds. The formal worker, formal Turn entry and centralized candidate use this value. Intent recognition, character decisions, world progression, narration, memory maintenance and scene corrections inherit the caller's deadline. A shorter deadline or cancellation takes precedence. Corrections share the existing deadline and call limits.

Model input, visible output, reasoning reserve and correction-count limits retain their existing values. Model calls occur outside the final world transaction. A failed or cancelled turn publishes no candidate narrative or world effects.

## Provider observation

`model.TextRequest.OnDelta` receives synchronous, provider-returned reasoning and response text before `GenerateText` completes. Deltas are transient observation; final responses still undergo transport, JSON and business validation.

DeepSeek requests SSE when an observer is present. Decoded reasoning plus response text remain bounded by `MaxResponseBytes`; SSE framing has a separate bound of sixteen times that limit. The stream requires a successful finish and the terminal marker. Incomplete streams, unsupported tool output and oversized text fail the request. Final usage is retained when supplied.

Providers that supply no reasoning text expose available call progress. The application supplies no substitute thinking text.

## Progress API

`GET /api/v1/worlds/{world_id}/runs/{run_id}/progress` uses the existing authenticated world ownership and run lookup. Responses use `Cache-Control: no-store`.

- `run_id`, `status`, `budget_seconds` identify the current attempt and budget.
- `calls` carries call ID, purpose, recipient, start time, phase and received text counts.
- Phases are `waiting`, `thinking`, `writing`, `received` and `failed`. `received` describes a provider response, not an accepted game result.
- `include_thinking=1` explicitly includes provider reasoning. Default requests omit its text.
- Reasoning retention is limited to 256 KiB across one run, with valid UTF-8 boundaries. Hitting the display limit leaves generation running.
- Terminal runs return no transient calls. Runtime teardown releases their retained reasoning.

Reasoning is not written into story messages, personal experiences, saves or diagnostic logs. Only validated scene results can become game facts.

## Reading interface

The existing waiting card shows current generation activity, elapsed waiting time and the 300-second limit. “模型思考 · 可能剧透” is an inline disclosure. It starts closed; opening it requests raw reasoning, and closing it clears the received text and resumes progress-only requests.

The disclosure identifies possible character secrets and backstage information. Only calls with reasoning or an active response appear in its body. Long text wraps and scrolls inside a bounded area. Network failures retain the waiting card and existing cancellation action. Late responses from a collapsed disclosure, another run or another world cannot update its content. Removing the card stops polling.
