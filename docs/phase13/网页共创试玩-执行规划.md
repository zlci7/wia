# 网页共创试玩执行规划

日期：2026-10-07。基线：`555c368`。状态：工程与网页验证已完成，用户实机评审待进行。证据见[网页试玩验收](records/网页共创试玩-验收.md)。

## 范围

在现有 A 方案页面提供新建共创试玩入口，复用阅读区、自然语言输入和纵向行动建议。试玩使用 `turn.CreationSession`，以完整接受后的正文、世界日期、当前位置和个人记录承接下一轮。剧本材料通过现有剧本包读取，通用实现保持剧本无关。

试玩会话由当前本地应用进程维护；刷新页面可以重新读取仍存在的会话，应用退出后会话结束。页面明确说明此生命周期。旧存档继续使用原有入口和机制；本轮不迁移旧存档、不扩展经济结算、不重做视觉设计。

## 交互合同

- 玩家原文提交到集中创作流程。默认关闭主动推进和模型思考；主动推进为逐回合选项。
- 流式与非流式传输分别选择。流式页面只呈现候选正文；完整校验后，正文、世界时间和位置一起生效。技术纠正时重置候选正文。
- 生成中可取消。失败与取消保留输入和上一轮接受后的情境；重复提交相同请求标识不重复调用模型。
- 正文先呈现，三个行动建议随后异步生成。建议复用现有生成职责和提示词，只读取当前玩家可见材料；按会话和接受回合绑定，过期建议失去发布资格。
- 建议纵向排列，点击填入草稿，玩家可修改后发送。已有草稿保持原状；建议失败时自由输入继续可用。
- 试玩页面只展示当前流程能维护的真实信息，不展示未经结算的资源状态，也不宣称自动存档成功。
- API 沿用本地访问、会话认证、请求校验与模型用量记录。普通回合沿用 300 秒总预算和既有调用限制；建议任务使用独立有界预算。

## 工作单元

| 单元 | 交付 | 验收 |
| --- | --- | --- |
| W1 会话与 API | 应用管理内存会话、请求幂等、后台生成、进度、取消；共享行动建议生成 | 接受与取消边界、重复提交、过期建议、关闭应用、玩家信息范围通过测试 |
| W2 页面接线 | 剧本页面的新试玩入口、A 方案阅读区、推进开关、传输选择、三个建议 | 草稿与阅读位置保持；取消和失败可恢复；刷新可承接当前进程会话 |
| W3 浏览器验收 | 真实模型连续游玩、受控失败与取消、桌面和窄屏截图 | 连续追问、多人交谈、私聊、移动和主动推进可在网页操作；结果与实际调用记录对应 |

预计 4～6 小时，最后约 1 小时保留给回归与收口。真实模型验证最多 16 次请求，包含建议和纠正；服务故障时保留失败事实，不扩大调用预算。

## 检查与交付

叙事改动执行 `go test ./... -count=1`、相关包 race、`go vet`。前端执行类型检查、相关机制测试与正式构建。以 gstack `/browse` 验证真实网页并保存截图；测试替身与真实模型证据分别记录。

按完整工作单元本地提交，交付浏览器入口、提交列表、验证结果与实际限制。模型密钥、本机配置和旧存档不进入提交。实际进度见[开发状态](开发状态.md)，整体职责见[架构](../summary/ARCHITECTURE.md)。
