# 轻量共创游玩

## 入口

在仓库的 `backend` 目录运行：

```powershell
go run ./cmd/wia-play
```

默认加载《雾都余烬》和 WIA 正式模型配置。模型配置顺序为 `-model-config`、`WIA_MODEL_CONFIG`、`%LOCALAPPDATA%/WorldIsAgent/story-app/config/model.json`。当前原型使用 DeepSeek 的显式思考选择和 JSON 输出模式。

直接输入自然语言行动。每个会话使用内存保存接受后的情境和人物记录，退出结束会话。

| 命令 | 含义 |
| --- | --- |
| `/advance on`、`/advance off` | 从下一轮选择是否允许主动增加剧情发展 |
| `/stream on`、`/stream off` | 从下一轮选择流式或非流式 |
| `/reasoning off`、`/reasoning low`、`/reasoning high` | 从下一轮选择思考模式 |
| `/quit` | 结束会话 |

默认关闭思考、关闭主动推进、采用非流式。流式片段是候选 JSON；完整校验成功后显示接受的正文。原始模型思考不写入测试记录。

## 连续测试

```powershell
go run ./cmd/wia-play `
  -inputs ../docs/phase13/records/evidence/co-creative-play-2026-10-07/investigation-inputs.json `
  -record investigation.json `
  -reasoning off -stream -max-calls 16
```

`-record` 要求新文件。输入文件为 1～15 项 JSON 数组，每项包含 `input` 和 `allow_plot_advance`。`-max-calls` 为本会话所有请求的硬上限，范围 1～32，包含材料补充、纠正和失败请求；它不提高已有费用授权。

## 创作合同

`turn.CreationSession.Interact` 接收玩家原文、推进选项、思考模式和传输选项。完整结果包含：

| 字段 | 要求 |
| --- | --- |
| `narrative` | 必填，完整场景正文，最多 6,000 字符 |
| `scene_changes` | 必填，世界耗时与结束位置 |
| `continuity_notes` | 可选，最多 12 项重要事项 |

`scene_changes.elapsed_minutes` 为 0～120 分钟，`positions` 列出每个已选人物的结束地点。程序检查人物与地点引用、当前地点到目的地的有向可达性，以及世界日期范围。它保存结束位置，不结算途中所有行动或数值资源。

连续性事项包含 `kind`、`content`、`recipients`，以及适用的 `speaker_id`：

- `observed`：实际观察。
- `statement`：有说话者的证词。
- `hypothesis`：尚未证实的推测。
- `commitment`：尚未兑现的约定。

事项保存给实际接收者，说话者也保留自己的记录。人物说法与约定保持各自性质。

## 上下文与记录

创作复用现有 `ContextGenerator`、`ContextComposer`、材料授权、个人 `MemorySource` 和有界整组检索。固定事实、创作空间和人物资料来自 v4 剧本包；通用提示词使用剧本数据中的人物与地点。

相关人物包括当前位置的人物、原文提及的人物、目的地人物，以及上一轮实际说话或获知重要事项的相关人物。近期互动按完整输入与正文装配；旧经历按本人范围检索。当前时间和位置在历史之后、玩家原文之前提供。

人物记录在当前会话的 `map[entity_id][]memory.MemorySource` 中维护，含个人顺序号、来源 ID、回合 ID、说话者、类型、内容和世界时间。`PersonalSources` 返回该人物记录的副本。记录与情境在完整结果校验后一起接受。

## 运行边界

普通回合一次核心调用。材料确有需要时沿用一次补充读取；格式或引用错误最多纠正一次，整轮最多三次核心调用，共享 300 秒截止时间与取消信号。截断、Provider 故障和取消直接保留上一轮情境。

内部会话入口与正式网页入口分别验收。正式应用仍使用 `Service.Execute`，数据库、用户存档与本机配置沿用原状态。原型不执行数值资源结算、固定判定或完整世界发展调度。

本地字段校验不能证明正文的每个语义判断正确。人物知情、玩家承诺、固定真相和细节连续性通过真实文本评审。

实际记录见[连续游玩验收](records/轻量共创-连续游玩验收.md)与[对话文本](records/轻量共创-对话文本.md)。
