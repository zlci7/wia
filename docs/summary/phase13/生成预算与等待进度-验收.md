Date: 2026-10-07. Provider/model: DeepSeek / `deepseek-v4-flash`. Real requests used an isolated world and the existing connection; player saves, secrets and local defaults were unchanged.

This establishes one successful question and live provider reasoning. It does not establish sustained conversation, private/public continuity, multiplayer quality, formal centralized save/load or a latency improvement. The successful round also fit within 60 seconds, so it does not isolate the effect of the longer budget.
