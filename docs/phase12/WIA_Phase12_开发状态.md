R01 另存恢复已补修：当前页面保留源世界、名称、请求键与版本，响应不确定时恢复原操作，取得任务 ID 后继续查询。4 项新增前端回归覆盖丢失响应、查询中断、明确失败及迟到结果。真实 HTTP 浏览器验证确认响应丢失后重试仅创建一个副本，仍停留原存档。当前前端 24 项设置/恢复及 4 项回顾机制测试、类型检查、正式构建、全仓 Go 回归及相关 race/vet 通过。M2 真实模型专项已验证纠正、另存、重启和继续生成。

回合恢复与行动衔接专项已交付：默认轮转诊断、模型调用与 JSON 校验分层错误、请求限时、按原幂等键确认提交、真实等待时间，以及 NPC 待执行提案与已说对白分离。协调保留 not_executed 结果及来源；公开对白保持可听范围。前端 19 项机制测试、全仓 Go 回归、相关 race/vet 与桌面及窄屏超时恢复专项通过。真实模型本专项共 6/7 轮完成，最新三轮 3/3；初次协调格式失败与剩余叙事偏差见 M1 验收记录，不代表长程稳定性验收。

故事设置提供场景协调、正文表达、NPC 共用决策三个高级策略入口。默认与自定义明确区分，显式选项优先，自定义替换默认；旧写作偏好合并到唯一正文策略入口。配置按世界保存、回合冻结、版本检查、另存继承，Composer 记录安全策略标识并检查容量。专项工程、浏览器与真实模型证据见 M1 验收记录。

NPC 初始关切由 definition 初始化并按世界保存，仅进入本人决策上下文；旧存档缺失保持为空。通用决策允许人物处理自身事务，沉默不阻止行动，协调根据实际条件处理结果。M2 通过个人回顾维护信念、关系、关切及约定，世界剧情按条件和游戏内时间推进。

故事上下文由 ContextComposer 统一构建。玩家原话与可听范围、最近四个成功回合对话、个人来源元数据、按接收者保存的场景视图、完整因果组预算及安全诊断已接入。NPC 回复沿用本人所在场景的公开对白；M2 接入连续个人回顾、完整近期尾部、受限检索、有效纠正与重建。

M1「核心游玩与可靠存档」提供可运行基线、设置编辑会话保护、自然收尾与弹性篇幅规则、协调阶段已完成行动的连续状态参考。工程与浏览器专项已有通过记录。当前版本真实 DeepSeek 五轮连续游玩完成 5/5；此前试验中的结构化输出失败与少量叙事越界均有记录，短样本不代表长程稳定或用户体验验收通过。

## M1 交付入口

```powershell
cd D:\data\project\game-agent\world-is-agent
.\scripts\start-phase12.ps1 -Rebuild
```

日常启动可使用 `.\scripts\start-phase12.ps1`；需要重新构建工作台时使用 `-Rebuild` 或 `-True`。也可以构建 `go build -o wia-runtime.exe ./runtime/cmd/server` 后直接运行。Runtime 日志会打印本地工作台地址；首次进入由工作台完成真实 Provider 连接验证。
