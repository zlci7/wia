# World Is Agent Phase12 文档

本目录只保留产品、架构、阶段实施和验证证据四类文档。新开发会话从本页进入，不需要逐份猜测文档优先级。

## 阅读顺序

1. [产品说明](产品说明.md)：用户体验、产品范围和验收目标。
2. [总体技术方案](总体技术方案.md)：跨阶段架构、身份、权限、事务和运行合同。
3. 当前阶段技术方案：该阶段的数据、接口、执行顺序和验证要求。
4. [开发指南](开发指南.md)：开发节奏、提交规则和验收责任。
5. [开发状态](开发状态.md)：当前真正完成了什么、还缺什么。

发生冲突时，产品说明决定产品目标，总体技术方案决定跨阶段合同，阶段技术方案决定本阶段实现，开发状态只陈述已有证据。

## 维护规则

- 产品目标只写入产品说明。
- 跨阶段不变量只写入总体技术方案。
- 阶段专属数据结构、接口、迁移和测试只写入对应阶段方案。
- 实际进度只更新开发状态；测试证据写入对应阶段验收记录。
- 已经并入阶段方案的专项文档不再单独创建，避免同一规则出现多个版本。
