# 模型主导的可选能力模块验收记录

日期：2026-10-01。合同：[设计方案](../stages/模型主导的可选能力模块.md)。

## 确定性验证

| 范围 | 验证内容 |
| --- | --- |
| 状态 | 模型更新整数、布尔和枚举；失败行动的状态后果；声明范围、固定预算、类型错误与整组回退 |
| 物品 | NPC 之间交付、模型确认的非持有人转移、拾取后离开、同一来源的顺序转移 |
| 关系与知识 | 本人解读经历涉及的其他人物；正数预算与无预算定义；已知他人物品、未获知物品及远处实时归属的裁剪 |
| 接入 | 可选能力独立应用，未启用能力拒绝变化；真实场外协调调用路径使用测试模型，核对地图、当前归属、状态定义、本人提案与完整字段合同 |
| 判定 | 同一输入复用骰点、目标与修正；固定结果不能被模型覆盖；同一规则结果的多次状态效果保留顺序 |
| 存储 | 同一来源多次状态变化完整提交，重复请求不重复生效，关闭后重新打开恢复当前值；旧索引升级保留状态与物品变化记录 |
| 纠正 | 没有状态效果的已结算判定也受纠正边界保护；拒绝后 epoch 不变；同规则多次结算的来源均被保留 |
| 内容 | model 策略的三种类型可编译；空规则目录中的无效引用被拒绝；新示例委托推进没有成功标记依赖 |
| 前端 | 桌面与手机入口复用 StatePanel；类型检查、现有设置／记忆／内容工具机制测试及正式构建通过 |

## 验证边界

本轮完成内部代码自查与自动化回归，没有独立上下文审查、真实模型连续游玩或新增浏览器实测。模型替身证明输入输出、提交和恢复机制，不能证明叙事质量。用户 CR 尚未完成。

真实体验使用独立新存档和 `mist-embers.pack.v4`，验证接受或拒绝委托后的持续记忆、拾取后离开、人物之间交付、状态变化、风险行动与重启继续。观察人物知情范围、物品归属及状态栏是否与叙事一致。模型输出仍无法满足数据合同时，该轮不提交，输入保留供重试；已准备的骰点继续复用。

已有世界保持冻结定义，默认内容目录切换与旧用户数据转换未执行。纠正涉及当前结构化事实或固定判定时，事实重建能力仍是已知限制。
