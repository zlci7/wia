## 验证边界

本轮完成内部代码自查与自动化回归，没有独立上下文审查、真实模型连续游玩或新增浏览器实测。模型替身证明输入输出、提交和恢复机制，不能证明叙事质量。用户 CR 尚未完成。

真实体验使用独立新存档和 `mist-embers.pack.v4`，验证接受或拒绝委托后的持续记忆、拾取后离开、人物之间交付、状态变化、风险行动与重启继续。观察人物知情范围、物品归属及状态栏是否与叙事一致。模型输出仍无法满足数据合同时，该轮不提交，输入保留供重试；已准备的骰点继续复用。

已有世界保持冻结定义，默认内容目录切换与旧用户数据转换未执行。纠正涉及当前结构化事实或固定判定时，事实重建能力仍是已知限制。

### 真实模型证据

接受委托路线连续完成七轮：取得委托资料、经过裁缝店和红烟囱街、抵达诊所、尝试潜入、与失踪女孩交谈、请求保管银镜。地点和同场名单随结构化移动变化；疲劳与调查负荷发生模型结算。潜入实际记录百分骰 52、目标 60、结果成功。女孩拾取银镜后拒绝交付，物品继续归女孩，玩家请求没有直接变成转移事实。

拒绝路线保留“不收钱、不拿资料、不承诺帮忙”，玩家可以离开事务所到咖啡馆；等待时裁缝店老板自行离开，玩家休息后疲劳下降。等待遇到到期事件时只推进到该时点，正文与保存的游戏时间对应。

最终空间合同的新存档完成“拒绝并去咖啡馆”：开放事件分别给玩家咖啡馆内的公开报纸信息、给记者其所在地获知的消息；记者本人响应后，经场外行动协调从报社移动到红烟囱街。数据库位置与玩家同场名单一致，玩家正文没有把远处记者写到咖啡馆。

另存分支从诊所离开并推进两轮至 09:58，其中第二轮在进程重启、浏览器重新连接后提交；原存档仍为七轮、09:48，玩家留在诊所。两份存档的银镜仍归女孩，原百分骰结果保留。分支玩家离开后，状态栏没有显示远处人物的实时物品。

累计完成十四个不同的真实模型回合，包括修复前对照；最终版本完成新存档两轮和另存分支两轮。一轮状态字段错误经现有一次修复后提交。最终浏览器重新连接后的控制台没有新增消息，重启期间的连接错误不计入该结论。样本是短程验证，不作为稳定失败率统计。

### 真实环境边界

修复前实测出现过开局输入预算超限、复合口头输入遗漏玩家移动、开放事件生成越过人物行动边界，以及事件接收者校验失败。最终代码对应的工程机制有回归；短程真实样本不能证明长期叙事完全一致。

模型仍可能产生字段错误或耗尽输出额度。一次场外协调响应将 12288 输出 token 全部用于推理，内容为空；共享调用时限内的修复随后超时。失败回合没有提交，输入保留。不能据此确认 Prompt 冲突就是长时间推理的原因，也不能将校验修复机制记成模型稳定性已解决。

NPC 之间交付、玩家拾取后离开和固定判定重试幂等已有确定性证据；本次真实模型样本尚未覆盖这些路径的全部组合。涉及当前结构化事实或固定判定的纠正仍受既有事实重建边界限制。默认内容切换、用户旧数据转换与稳定发布验收尚未执行。
