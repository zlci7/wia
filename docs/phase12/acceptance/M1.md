## M1 能力

- 本地浏览器工作台直接进入故事，不依赖旧 Adapter 或游戏进程。
- 旧渡口客栈场景包含沈岚、铁杉两名重要 NPC 和 10 名有身份的旁观者。
- 私聊内容按接收者分发；未被告知的角色只能获得可见但听不清的感知。
- NPC 的反应并行生成，公共回复按角色顺序稳定呈现。
- NPC 主动性按存档支持回应为主、按情境主动和积极互动；默认按情境主动，普通进入、环顾和走动不会机械触发所有 NPC 发言，观察、等待和维持姿态不会作为需要协调结果的新行动。
- 回合先解析玩家意图、直接对象和可见范围；合法的模型语义结果不会被全文关键词再次覆盖。
- NPC 的 speech、action_intent、silent、memory 均进入各自边界；协调阶段把每个行动尝试解析为有来源的结果，人物按实际可见范围获得结果感知。
- 协调和玩家正文使用独立调用；最终正文只接收玩家可见对白与结果投影，不接收 NPC 私人记忆或隐藏结果。
- 玩家行动以明确来源进入正文投影；默认正文使用“你”的第二人称有限视角，不把主角改写为“来人”或“来客”，也不使用主角无法确认的全知判断。
- 默认自然共创允许把已表达意图补成等价的简短台词、日常动作和即时反应；克制扮演与小说共创提供不同主角补写幅度，但都不能新增 NPC 决策、替玩家作关键选择或改变下一轮持续状态。
- 故事设置按存档保存主角补写幅度、NPC 主动性、正文人称、篇幅、描写密度和补充写作偏好；三个互动风格作为快捷预设，高级设置可拆分调整，另存继承设置，运行中的回合不会被中途改写。
- 私聊进入正文调用前会脱敏为交谈事实，耳语原文不会通过玩家行动事件泄漏给正文 Agent。
- 第二阶段保留每名 NPC 自己在第一阶段获得的感知与个人决定，同时接收新的公开刺激。
- 只有当前在场人物参与本轮；回合结束后的场景与在场名单随事件、感知和正文在同一事务中提交，进入或离开不会回填此前阶段的信息。
- 输入运行支持完成、取消、失败、重试和请求幂等；失败与取消不会进入正式对话历史。
- 重试绑定稳定 input_id、attempt、输入接受顺序和原世界基线；任何后续新输入一旦接受，更早输入即失去重试资格，旧存档中没有可信序列的失败项不会被直接重放。
- 工作台默认进入首页；首页只提供继续当前故事和选择剧本。选定剧本后，剧本详情按 game_id 展示新建、继续、读取和删除；游玩页的存档入口也只显示当前剧本。
- 当前世界与页面导航彼此独立，返回首页不取消生成或推进时间；删除当前存档后停留在所属剧本详情，不自动激活其他存档。
- 世界支持自动保存、另存为新世界、激活切换、删除和重启恢复；当前及非当前存档均可经确认删除，活动运行或另存期间会阻止删除。
- 每个世界同时只允许一个待另存任务；另存只在绑定回合完成边界发布，复制任务在退出前取消并排空，复制状态与世界状态使用同一应用事务。
- 模型连接验证通过后使用版本化密钥和原子配置发布；发布失败时上一组配置与密钥保持可启动状态。
- 页面刷新可从服务端恢复进行中和失败回合；空运行列表稳定返回数组，用户清空失败输入后轮询不会重新填回；本地 API 校验 Host 与 Origin。
- 每个世界独立保存事件、感知、记忆、消息、角色状态和运行状态。

| 回合反馈 | 使用实际 run 状态与已读取正文判断保存；回复到达时保持玩家后来上翻的位置 |

## 用户体验验收

既有工程和浏览器验证覆盖前述基线交互机制；设置编辑专项及叙事节奏补强仍待实现与验证，真实模型的叙事质量与最终用户体验仍待验收。手机只完成视口模拟，实体手机软键盘尚未验证。

本轮交付包含 `console/dist` 正式页面构建及 `bin/wia-runtime.exe`。浏览器测试已启动真实服务 API 并加载正式页面；独立可执行文件的进程启动探测被执行环境策略拦截，因此本轮仅记录其构建通过，不将服务 fixture 的启动冒充可执行文件启动验证。

建议体验路径：

1. 打开首页，查看剧本，再按默认主角与名称开始；未配置时连接模型，确认回到主角表单而不自动开局。
2. 在游玩页点击沈岚，使用 Ctrl+Enter 发出问候；向上阅读时确认顶栏、输入区可用，新回复不抢走位置。
3. 打开故事设置，调整互动风格或回复长度；另存后确认仍在原存档，切换两个存档检查草稿与阅读位置。
4. 在实体手机浏览器打开可访问的部署地址，呼出中文键盘，检查输入框、提交按钮、正文滚动和键盘收起后的恢复。M1 本地服务仅允许回环地址，不为此验收自动开放局域网访问。

## M1 范围边界

M1 已覆盖产品要求中的普通游玩、两名重要 NPC、旁观者、私聊隐私、可靠运行、自动保存、另存为和世界切换主链路。真实 Provider 的正式对话验收需要运行环境提供 DeepSeek 或 OpenAI API Key；Fake Generator 仅用于自动化测试。M1 不包含后续阶段的完整世界剧情、长期记忆工作台、桌面安装包和服务器部署。
