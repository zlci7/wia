# 失踪案已成立事实

裁缝店老板的女儿离家三天。父亲担心她，也习惯替她安排生活。两人最后一次见面发生过争执；父亲在委托中隐瞒了争执的重要性，也没有主动交代女儿收到过一张来自红烟囱街的收据。

女孩主动接触过裂纹银镜。经济压力与家庭冲突影响了她的选择，但她有自己的判断，不应只被描述为等待营救的人。开场时她在废弃诊所，银镜也在诊所；她过去接触银镜并不表示一直持有它。

亚瑟以钟表匠的公开身份生活，私下作为机械之心外围人员留意危险物品流入民间的线索。他知道编号 3-917 的银镜可能流入东区，尚未核实它是否仍在某个具体地点。

艾琳知道有人打听红烟囱街和旧诊所，尚不知道银镜规则与亚瑟身份。她自己的采访兴趣不等于玩家已经接受委托。

开场没有任何人因玩家尚未作出的选择形成承诺。银镜来源中尚未确立的细节保持未知；后续调查可以形成新事实。
