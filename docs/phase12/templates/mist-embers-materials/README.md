## 结构化配置映射

| 现有内容 | 新修订配置 |
| --- | --- |
| `background` | 精简背景与城区材料 |
| `rules` | 世界设定进入异常材料；应用执行规则由系统合同提供 |
| `author_facts` | 案件真相、银镜规则及各人的知识分别保存 |
| `locations` | 保留 ID 和有向路线，保存到 `world/locations.json`；公开说明只写可观察部分 |
| `npcs/*.json` | 保留实体 ID、身份、外观、性格、初始位置和状态；长知识与计划采用材料引用 |
| `item_definitions` | 银镜公开外观和稳定定义 ID；完整能力使用作者材料 |
| `item_instances` | `mirror-3-917` 初始在 `abandoned-clinic`；之后归属只读当前存档 |
| 委托窗口节点 | 委托人生活压力、女孩自主意愿与调查进展材料 |
| 银镜回收节点 | 亚瑟本人计划，重新检查时使用本人线索与当前世界事实 |
| 潜入判定 | 保留当前固定判定合同 |

开场地点保持事务所，裁缝店老板在场，女孩在诊所，亚瑟在钟表铺，艾琳在报社。女孩已经接触银镜与银镜当前在诊所分别描述，接触经历不等于当前持有。

地图中的诊所公开说明使用“红烟囱街尽头一栋停业的旧诊所，窗板松动，屋内缺少日常照料”，地下室入口位置进入相关观察或私人来源。事务所通信陈设采用留言、书信与城区地图；公用电话的原作时间依据尚未核实。

## 参考范围

世界题材依据包括蒸汽工业与非凡隐秘生活：出版方简介明确提及工厂、枪械、飞空艇、魔药、占卜和封印物。[Yen Press 第一册](https://yenpress.com/titles/9798855413779-lord-of-mysteries-vol-1) 第四册的出版简介包含煤气灯、列车和侦探活动，可支持生活与调查氛围。[Yen Press 第四册](https://yenpress.com/titles/9798855414295-lord-of-mysteries-vol-4)

本剧本采用第一部结束后、愚者教会已经存在的同人分支：战争后的贝克兰德与局部失踪案。具体开场日期尚未固定。具体街道、店铺、四名人物、案件与银镜能力为剧本设定，不声称来自原作档案。背景以[原始设计材料](../../WIA_开放型剧本产品设想与诡秘之主测试剧本设计材料_v1.0.md)第 31、39、42 节及当前包为依据。

主题资料与出处见[诡秘世界作者参考目录](../../reference/诡秘世界/README.md)。通识者的记忆、学习与实践能力采用作者公开设定；亚瑟的序列身份沿用原始设计材料，他掌握的银镜编号与风险来自剧本设定的外围线索。战后蒸汽教会收缩和鲁恩币制采用已阅读的社区资料，保持 B 级参考；亚瑟的具体地方身份、联络与任务为同人设定。

银镜的 `3-917` 是同人档案编号。精确危险评级、原作编号是否已占用、机械之心的具体权限、战争结束的精确日期和电话普及时间仍需原文核对。资料库保存出处与时间适用范围，运行材料只读取索引选入的正文。
