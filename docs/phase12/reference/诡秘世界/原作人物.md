## 续作人物

**证据 B，续作时代。** 卢米安·李为《宿命之环》主角，奥萝尔与其背景及卷毛狒狒研究会相关。其具体经历和组织关系属于续作材料，不能默认成为第一部结束后这个街区的公开事件。[宿命之环](https://zh.moegirl.org.cn/宿命之环)、[隐秘组织](https://zh.moegirl.org.cn/诡秘之主/隐秘组织)。
