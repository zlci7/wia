# 时代与地理

## 世界背景

**证据 A，跨时代背景。** 世界具有蒸汽工业、枪械、工厂、飞艇与机械计算装置；魔药、占卜与危险非凡物品隐藏在日常社会之下。煤气灯、铁路与侦探活动适合构成城市调查的公开表层。[Yen Press 第一卷简介](https://yenpress.com/titles/9798855413779-lord-of-mysteries-vol-1)、[第四卷简介](https://yenpress.com/titles/9798855414295-lord-of-mysteries-vol-4)。

## 地理参照

**证据 B，第一部背景。** 鲁恩位于北大陆，首都贝克兰德沿塔索克河展开。因蒂斯首都为特里尔。罗思德群岛位于苏尼亚海，拜亚姆与第一部后期的海神信仰、愚者教会人员和白银城、月城居民有关。国家与群岛的存在不表示当前地图开放全部地区。[世界地理](https://zh.moegirl.org.cn/诡秘之主/世界地理)、[鲁恩王国](https://zh.moegirl.org.cn/鲁恩王国)、[世界历史](https://zh.moegirl.org.cn/诡秘之主/世界历史)。

**证据 A，第四纪历史。** 作者公开设定将贝克兰德列为图铎—特伦索斯特联合帝国及特伦索斯特帝国的重要首都，特里尔对应图铎帝国的首都。这为现代城市的古老遗产提供历史背景；具体遗迹位置与内容仍需各自来源。[乌贼《诡秘设定（8）》](https://mp.weixin.qq.com/s/kGYEpGyr4ftQ8i2BxB3THA)。

## 开场时代

| 范围 | 时间与适用性 |
| --- | --- |
| 本剧本，C | 第一部结束后，战争已经结束，愚者教会已存在；开场具体日期未固定。 |
| 第一部结尾，B | 克莱恩成为愚者并进入沉睡；白银城、月城居民走出神弃之地，愚者阵营已有组织与人员。[克莱恩](https://zh.moegirl.org.cn/克莱恩·莫雷蒂)、[世界历史](https://zh.moegirl.org.cn/诡秘之主/世界历史)。 |
| 续作开场，B | 社区综述将《宿命之环》开场放在第一部结束约六至七年后，叙事转向卢米安及因蒂斯等地区。[宿命之环](https://zh.moegirl.org.cn/宿命之环)。 |
| 未核实 | 第一部结尾到本剧本开场的精确间隔、愚者教会在贝克兰德的公开覆盖程度、当地具体分支组织。 |

续作后期的苏醒、组织扩张和神灵格局变化分别属于更晚时间。开场人物不会因为作者读过续作而提前掌握这些结果。
