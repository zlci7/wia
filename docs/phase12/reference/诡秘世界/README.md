## 证据等级

| 等级 | 含义 |
| --- | --- |
| A | 已读取作者公开设定或正版出版方正文。证据仅覆盖对应页面明确写出的内容。 |
| B | 已读取社区整理正文；具体原作章节尚未逐条复核。 |
| C | 项目同人设定或可选适配。 |
| 未核实 | 没有充分正文证据，不作为确定的原作事实。 |

初始网页阅读记录日期为 2026-10-01；本轮关键资料复核日期为 2026-10-04。两次记录分别保存在来源索引中，未复核条目沿用原有等级与日期。社区人物与神灵页面可能同时包含两部小说的状态，资料中的时间标签具有优先权。各主题采用简短事实摘要和出处，原作全文与百科正文不收录。

## 关键事实条目

关键条目使用稳定 ID：`LOTM-TIME-*`、`LOTM-GEO-*`、`LOTM-MONEY-*`、`LOTM-LIFE-*` 和 `MIST-*`。每条记录结论、年代或地区、来源与定位、核验日期、等级、可用范围和未知项。编号不随段落移动改变，剧本材料可引用编号追溯依据。

证据 A 还需注明来源类型：原作正文、作者公开补充或出版方简介。出版简介只证明其中明确概述的世界背景。合理推测必须显式写为推测；作者选择写为 C；有章节线索但未读取正文的条目保持未核实。

本轮鲁恩币制和零钱面额已复核社区正文，保持 B；《宿命之环》的日期及第一部金额例子的正版链接受网站验证限制，本轮未获得正文。前序研究中声称读到这些内容的记录作为复核线索保存。

## 信息适用范围

本目录属于开发者参考资料。运行材料从其中选择与当前场景相关的事实，并按接收者与用途裁剪。

- 普通人物可以知道城市、币制、公开信仰与亲历事件。
- 人物掌握的非凡知识、组织身份、物品能力和私密计划分别来自其经历或可靠来源。
- 作者知道的案件真相、神祇身份与续作结局属于作者资料。
- 原作人物索引不改变剧本的固定 NPC 名单；历史节点不构成必须发生的任务或结局。

精确设定以作者原文和正版原作章节复核结果为准。
