# 教会与隐秘组织

## 教会参照

下表为**证据 B**。地区是主要关联范围，不能据此推定每条街都有相应组织。传统“七大正统教会”的历史称呼与第一部战后的实际状态分别处理。[神灵](https://zh.moegirl.org.cn/诡秘之主/神灵)、[世界历史](https://zh.moegirl.org.cn/诡秘之主/世界历史)。

| 教会 | 常见地区或社会关联 | 第一部结束后的适用状态 |
| --- | --- | --- |
| 黑夜女神教会 | 鲁恩；值夜者 | 战后仍活跃；战争之神陨落引起的信仰与组织接收属于战后背景。 |
| 风暴之主教会 | 鲁恩、海上与岛屿；代罚者 | 仍活跃；罗思德当地事务有自己的政治与信仰变化。 |
| 蒸汽与机械之神教会 | 因蒂斯、工业与技术；机械之心 | 在鲁恩战败后受到削弱，不能沿用战前完整编制与资源。 |
| 永恒烈阳教会 | 因蒂斯；净化者 | 仍活跃；因蒂斯宗教与社会背景按当地资料处理。 |
| 大地母神教会 | 费内波特及相关医疗、生命信仰 | 仍活跃；具体地方机构需要独立设定。 |
| 知识与智慧之神教会 | 伦堡等地；知识与读者途径 | 仍活跃；不推定贝克兰德存在常设调查队。 |
| 战神教会 | 弗萨克历史信仰 | 战争之神已在第一部战争中陨落；普通信众的获知与组织转变具有时间差。 |
| 愚者教会 | 罗思德、白银城与月城相关人群 | 已存在；本地公开认可、分支规模与传播范围分别核实或明确为同人设定。 |

## 战后蒸汽教会

**证据 B，第一部后期。** 社区历史整理记载，蒸汽教会在鲁恩仅保留少量教堂，较高层次人员及二级以上封印物迁出。这支持战后力量收缩的背景，不证明贝克兰德每个基层成员都已离开。[世界历史](https://zh.moegirl.org.cn/诡秘之主/世界历史)。

**证据 C，雾都余烬。** “仍有机械之心外围线索人员，以钟表匠身份留意危险物品流入民间”是可采用的局部同人设定。亚瑟的具体上级、权限、薪酬、档案和物资均由剧本明确，不能从战前组织名称自动推导。

## 愚者教会的事实范围

**证据 B，第一部结尾。** 阿尔杰、戴里克、达尼兹与愚者信仰的组织或传播有关：戴里克关联白银城与愚者教会，达尼兹承担神使角色，阿尔杰的海神体系与愚者的安排相关。具体人物身份和神祇关系不是所有普通信众的共同知识。[阿尔杰](https://zh.moegirl.org.cn/阿尔杰·威尔逊)、[戴里克](https://zh.moegirl.org.cn/戴里克·伯格)、[达尼兹](https://zh.moegirl.org.cn/达尼兹·迪布瓦)。

“愚者教会存在”不能直接推出“贝克兰德街区已有公开教堂”“所有居民都了解愚者与海神的关系”或“教会已被全球正式承认为正统”。这些地方性、法律性与认知事实目前未核实。

## 隐秘组织

**证据 B。** 塔罗会、心理炼金会、密修会、魔女教派、玫瑰学派与极光会构成可供作者查阅的组织背景。其成员、内部派系、任务与秘密分别由人物实际知识限定；不能因组织存在就让它们全部介入一宗街区案件。[隐秘组织](https://zh.moegirl.org.cn/诡秘之主/隐秘组织)。

续作中的塔罗会扩张与卷毛狒狒研究会资料标记为**续作时期**。原作组织名称可以作为背景，具体在场人员与当前行动仍需独立来源。
