# 雾都余烬设定边界

## 时代与场景

**证据 C。** 场景位于第一部结束后的贝克兰德有限街区。战争已经结束，愚者教会已存在；具体年月、街道、店铺与案件由剧本确定。

工业城市与侦探生活有出版方背景支持，战后教会格局采用 B 级社区资料。各项出处分别见[时代与地理](时代与地理.md)、[教会与隐秘组织](教会与隐秘组织.md)和[社会生活](社会生活.md)。

## 固定人物

| 人物 | 项目设定，C | 原作约束与资料来源 |
| --- | --- | --- |
| 裁缝店老板 | 女孩的父亲，面临家庭与经济压力。 | 城市经济与阶层作为背景；具体家庭经历为原创。 |

| 艾琳 | 年轻记者，持有部分街区线索。 | 报纸与采访采用城市背景；她的消息渠道、采访动机和知情程度为原创。 |

## 裂纹银镜

**证据 C。** 银镜实例、外观、同人编号 `3-917`、愿望景象和认知风险由独立物品档案定义。它与原作阿罗德斯、通灵者的镜子分别存在。

作者层保存真实能力与代价。女孩掌握接触经历，亚瑟掌握已有档案或线索，其他人物通过观察、交流或实际使用获得信息。开场所在地、过去接触者与当前持有人是不同事实。

## 尚未确认的原作细节

- 第一部战争结束的精确日历日期与当前开场间隔。
- 愚者教会在贝克兰德的具体教堂、法律地位、传播范围与普通居民认知。
- 蒸汽教会在战后贝克兰德的基层编制，以及机械之心外围人员的正式权限。
- `3-917` 在完整原作档案中是否已使用，以及其正式危险评级。
- 战后电话普及程度、具体街区物价与购买力。

上述内容可明确采用同人配置。未核实状态不等于原作禁止，也不等于已有原作证据。
