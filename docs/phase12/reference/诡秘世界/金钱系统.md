# 金钱系统

## 鲁恩货币

**证据 B，第一部制度参照。**

| 单位 | 换算 |
| --- | --- |
| 金镑 | 1 金镑 = 20 苏勒 |
| 苏勒 | 1 苏勒 = 12 便士 |
| 便士 | 1 金镑 = 240 便士 |

币制换算来自已阅读的社区国家资料，尚未逐项核对对应原作章节。鲁恩的钱币与纸币均有使用场景。[鲁恩王国](https://zh.moegirl.org.cn/鲁恩王国)。

## 因蒂斯货币

**证据 B，续作参照。** 因蒂斯使用费尔与科佩：1 费尔 = 100 科佩。资料中出现约 24 费尔折合 1 鲁恩金镑的参照，属于相应故事时期的跨国比较，不构成战后长期固定汇率。[因蒂斯共和国](https://zh.moegirl.org.cn/因蒂斯共和国)。

## 街区金额与购买力

**证据 C。** 《雾都余烬》以鲁恩货币表述钱包、报酬与支出。具体初始金额、一次马车费、租金、饮食费和委托报酬由剧本配置。

战前价格、续作价格和不同地区价格分别保存。币制转换可以稳定处理，购买力与交换意愿仍由当时情境决定。百科中的现代人民币类比不是世界内事实。

人物知道自己看见、持有或经可靠渠道了解的金额。作者层的钱包、账目与第三方交易记录不因货币单位相同而自动公开。
