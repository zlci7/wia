# 社会生活

## 城市公开生活

**证据 A，第一部城市背景。** 蒸汽工业、煤气灯、铁路、机械与侦探业务是公开生活的一部分，非凡力量与危险物品构成隐秘层。[Yen Press 第一卷](https://yenpress.com/titles/9798855413779-lord-of-mysteries-vol-1)、[第四卷](https://yenpress.com/titles/9798855414295-lord-of-mysteries-vol-4)。

**证据 B，第一部基线。** 贝克兰德有商业、工业、码头与贫困地区，贵族、工商业阶层、工人和失业者的生活条件明显不同。警察处理公开治安，教会非凡人员处理超出普通警务能力的事件。学校、教会救济、慈善与报纸构成社会生活的一部分；其战后规模和人员不能直接照搬战前描述。[鲁恩王国](https://zh.moegirl.org.cn/鲁恩王国)。

## 交通与通信

**证据 B，第一部基线。** 城市公共马车、轨道交通与蒸汽铁路可以作为交通参照。跨海电报线路与电报通信存在，世界仍受航程、天气与运输条件限制。[鲁恩王国](https://zh.moegirl.org.cn/鲁恩王国)、[世界地理](https://zh.moegirl.org.cn/诡秘之主/世界地理)。

当前街区通信可明确采用书信、留言、报纸和当面传话，归入**证据 C 的剧本设定**。第一部战后公用电话的普及程度未核实，不能据此默认事务所具有随时联系任何人的电话设施。

## 工业发展与战后变化

**证据 B，历史背景。** 罗塞尔与蒸汽技术、工业发展及因蒂斯政治变革有关。第一部战争造成国境、教会力量与城市生活的变化。贝克兰德的战后重建、人员流动和经济压力可以构成局部案件的环境，但具体失业率、物价涨幅与某条街的受损情况没有直接证据。[世界历史](https://zh.moegirl.org.cn/诡秘之主/世界历史)。

**证据 C，雾都余烬。** 裁缝家庭的经济压力、停业旧诊所、钟表铺的日常经营和记者的采访兴趣属于这个街区的具体设定。它们描述人物能够观察和经历的生活，不自动确定谁犯罪、谁接受委托或谁必须离开家庭。

## 续作社会参照

**证据 B，续作时代。** 特里尔及因蒂斯乡村提供不同于鲁恩的城市、教育、宗教与贫困背景。它们可供其他剧本取材；本剧本的贝克兰德街区保持自己的制度、交通与货币。[因蒂斯共和国](https://zh.moegirl.org.cn/因蒂斯共和国)、[宿命之环](https://zh.moegirl.org.cn/宿命之环)。
